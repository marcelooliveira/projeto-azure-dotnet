# Vídeo 1.5 – Explorando o Azure Portal 

Contexto: 
A VollMed precisa começar a estruturar sua aplicação na nuvem, e o Azure Portal é a porta de entrada: uma interface gráfica amigável para criar e gerenciar recursos. 

Problema: 
 Porém, para quem está começando, o Portal pode parecer complexo — há muitas opções, menus e serviços, o que pode gerar confusão e atrasar as primeiras configurações. 

Solução: 
 Vamos explorar o Azure Portal na prática, navegando pelos principais menus, localizando os serviços mais importantes e criando o primeiro recurso da VollMed, organizado dentro do Resource Group que definimos anteriormente. 

Teoria: 

O Azure Portal é uma GUI (Graphical User Interface) que facilita a gestão de recursos sem exigir comandos. 

Vantagens: aprendizado rápido, visualização centralizada, ideal para começar. 

Limitações: pode ser menos eficiente para automação em larga escala; para isso, existem o Azure CLI e o uso de Infra as Code (IaC), como ARM Templates ou Bicep.
